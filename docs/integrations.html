Bring attention checks into your workflow

One local core, several entry points. These integrations are planned interfaces from the specification; installed behavior remains unverified.

ShareX: send a screenshot

  1. Install the Glance CLI and select a model.
  2. Create a ShareX custom action using the command below.
  3. Capture a screenshot, run the action and inspect its local result.
glance analyze "$input" --open

TODO-verify: ShareX file placeholder expansion and CLI --open support. If unavailable, save the capture and run glance analyze screenshot.png --out out/ --json.

Chrome and Firefox: analyze a visible tab

Build the Manifest V3 extension with npm run build:ext in app/ui. Load dist/chrome in Chromium browsers or dist/firefox in Firefox. UNISAL runs inside the extension; no local server is needed. Capture a visible tab to see its heatmap, squint test, gaze order and clarity.

Options can download SUM or TranSalNet, with SHA-256 verification and browser-local storage. Desktop server mode remains available for larger models. No store listing is available here.

Figma: analyze a selected frame

The planned plugin exports your selected frame to the local API. Development network access to localhost must be permitted. Figma's current plugin network policy, HTTPS behavior and distribution setup are TODO-verify; do not assume every desktop or web client can connect.

MCP: connect a local client

With a supported CLI installed, merge this server into Claude Desktop or Cursor configuration. Use an absolute path if the client cannot resolve glance.

{"mcpServers":{"glance":{"command":"glance","args":["mcp"]}}}

Claude Code:

claude mcp add --transport stdio glance -- glance mcp

Planned tools: analyze_image, compare_images, list_models. Runtime/tool compatibility is TODO-verify.

Glance inference is local. A connected client may transmit image paths, tool results or conversation content to its own service. Check that client's policies before using confidential work.

Local API: protect the boundary

glance serve

Target address: http://127.0.0.1:7878. Requests require Authorization: Bearer <token>, using the secret stored in ~/.glance/token. Do not publish that token or expose the service to the network.

Planned routes: GET /v1/models, POST /v1/models/{id}/install, POST /v1/analyze, POST /v1/compare, POST /v1/video. Analyze accepts multipart image, optional model and optional JSON aois.

Questions before you start

Are the integrations installed with this documentation?

No. These pages describe planned integration contracts. Packaging and runtime verification are pending.

Are MCP results always private?

Local inference keeps processing on your computer. An MCP client has separate data handling and may send results to an external service.
