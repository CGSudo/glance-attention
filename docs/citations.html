Redistribution boundary

SUM and TranSalNet have MIT code licenses in SPEC; UNISAL has Apache-2.0. Weight and dependency rights require verification. EyeFormer and DeepGaze IIE remain user-import only under SPEC’s no-license policy. Dataset files are not mirrored.

SUM ONNX export and selective-scan support are unverified. If export cannot pass parity checks, exclude it from v1 and record the outcome in CITATIONS.md.

Questions before you start

Does Glance record my eyes?

No. Glance predicts likely attention from an image. It does not record gaze or use a camera.

Is Glance free?

Glance is a free, open-source desktop app in development. Its own code is MIT; model assets have separate terms.
